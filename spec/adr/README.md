# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for the community-skills repo.

## Format

ADRs follow the template in the Green Irony Labs Working Agreements (Notion).
Filename convention: `ADR-NNNN-short-title.md` where NNNN is a zero-padded integer.
